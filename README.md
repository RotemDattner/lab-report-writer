# מדריך התקנה ושימוש – סקיל דוחות מעבדה

## מה הסקיל עושה

נותנים ל־Claude את חוברת הניסוי, והוא מכין לכל ניסוי שלושה מסמכי Word בעברית, עם נוסחאות אמיתיות שאפשר לערוך, ומספור אוטומטי של איורים, טבלאות ונוסחאות:

- דוח מכין – תשובות לכל שאלות החוברת, ממוספרות בדיוק כמו בחוברת.
- מסמך הכנה עצמית – ללמידה אישית עד רמת מוכנות לבוחן. כולל מושגים, נוסחאות עם דוגמאות פתורות, המעגלים צעד אחר צעד עם גרפים מהסימולציות, סימולציות הדגמה, מלכודות נפוצות, צ'קליסט למעבדה, בוחן לדוגמה עם פתרונות ודף נוסחאות.
- דוח מסכם – לפי פורמט 2026, בגוף שלישי. לפני המעבדה זה שלד; אחרי המעבדה מכניסים את צילומי הסקופ והמדידות.

בנוסף לכל ניסוי:
- סימולציות MATLAB לכל מעגל, עם השוואה אוטומטית לחישוב התאורטי.
- קבצי netlist ומדריך בנייה צעד אחר צעד ל־Multisim.
- קובץ QA.md שמפרט מה נבדק, מה עבר ומה מודגש בצהוב לבדיקה שלך.

התפקיד שלך: לבדוק את הסימולציות, לקרוא ולאשר את הכתיבה, ולכתוב את המסקנות.

## התקנה – פעם אחת

1. מורידים את הסקיל לתיקיית הסקילים של Claude. ב־Windows זו התיקייה הראשונה, וב־Mac/Linux השנייה:

```
C:\Users\<user>\.claude\skills\
~/.claude/skills/
```

   הדרך הקלה היא git. פותחים טרמינל בתיקייה הזו ומריצים:

```
git clone https://github.com/RotemDattner/lab-report-writer.git
```

   בלי git: בעמוד של הריפו לוחצים על הכפתור Code ואחר כך על Download ZIP, ומחלצים לתיקייה הזו. אם נוצרה תיקייה בשם lab-report-writer-main, משנים את השם ל־lab-report-writer.
   בסוף צריכה להיות תיקייה בשם lab-report-writer, ובתוכה הקובץ SKILL.md. כדי לעדכן לגרסה חדשה, מריצים git pull בתוך התיקייה.
2. מתקינים את PyMuPDF – פותחים טרמינל ומריצים:

```
python -m pip install pymupdf
```

   לשלב שאחרי המעבדה צריך גם את החבילות האלה. אפשר להתקין אותן עכשיו או כשיגיע הזמן:

```
python -m pip install numpy pillow lxml
```

3. מתקינים LibreOffice מהאתר הרשמי (התקנה רגילה).
4. בודקים שהכול עובד – מריצים את בדיקת ההתקנה. ב־Windows השורה הראשונה, וב־Mac/Linux השנייה:

```
python %USERPROFILE%\.claude\skills\lab-report-writer\scripts\selftest.py
python ~/.claude/skills/lab-report-writer/scripts/selftest.py
```

   בסוף צריך להופיע READY. אם מופיע FAIL, ההודעה מסבירה מה חסר.
5. MATLAB (מומלץ): מתקינים את MATLAB MCP Core Server לפי ההוראות הרשמיות של MathWorks ומחברים אותו ל־Claude Code. את ההוראות מוצאים בחיפוש של שם התוסף.
   - לפני כל עבודה עם סימולציות: פותחים MATLAB ומריצים בחלון הפקודות:

```
shareMATLABSession
```

   - אם מתקבלת השגיאה Unrecognized function, התוסף לא נמצא בנתיב. מריצים קודם:

```
addpath(fullfile(getenv('APPDATA'),'MathWorks','MATLAB Add-Ons','Toolboxes','MATLAB MCP Core Server Toolbox'))
```

   (ב־Mac/Linux התיקייה נמצאת בתיקיית ה־Add-Ons של MATLAB.)

## הכנת תיקיית הקורס – פעם אחת לכל קורס

יוצרים תיקייה לקורס (למשל "מעבדה 2"), ובתוכה:

- הקובץ course.json (הסבר מיד בהמשך).
- תיקייה עם חוברות הניסויים כקבצי Word (למשל "חוברות"). כל ניסוי – קובץ אחד.

Claude יוצר בעצמו את תיקיות הניסויים לצד החוברות.

את הקובץ course.json מעתיקים מ־assets/course.example.json שבתוך הסקיל וממלאים:
- שם המעבדה;
- שמות, תעודות זהות ופרטי קשר של המגישים;
- שם תיקיית החוברות.

הפרטים האלה מופיעים בעמוד השער. הם נשמרים רק אצלך, בתיקיית הקורס, ולא בתוך הסקיל.

יש בקובץ עוד שני שדות:
- max_pages_summary – מגבלת העמודים של דוח מסכם (ברירת מחדל 15). אם הדוח ארוך יותר, מתקבלת אזהרה.
- scope_width_cm – רוחב צילומי הסקופ בדוח (ברירת מחדל 11 ס"מ).

לוגו: הסקיל לא כולל לוגו. שומרים את הלוגו של המוסד בתיקיית הקורס בשם logo.png, או כותבים שם אחר בשדה logo. בלי לוגו, עמוד השער פשוט יוצא בלעדיו.

## שימוש

פותחים את Claude Code על תיקיית הקורס וכותבים בעברית רגילה, למשל:

- "תכין לי את ניסוי 2 – דוח מכין, מסמך הכנה עצמית ודוח מסכם"
- "תכין אותי לבוחן של ניסוי 3"
- "צילמתי את הסקופ ושמרתי בתיקיית images, תריץ מחדש"

העבודה מתקדמת בשלבים, ו־Claude עוצר לאישור שלך בין השלבים:

1. קריאת החוברת – Claude מציג את מבנה השאלות, והיכן ששאלה לא חד־משמעית הוא מצטט אותה במלואה ושואל אותך.
2. דפי נתונים וסימולציות – Claude מוריד דפי נתונים (באישורך) ומריץ סימולציות.
3. כתיבת שלושת המסמכים ובדיקתם – בדיקה אוטומטית, סקירה של כל עמוד ושלושה סוקרים בלתי תלויים.
4. דיווח – Claude מעדכן את QA.md ואומר לך מה מודגש בצהוב לבדיקה.

לכל ניסוי נוצרת תיקייה בשם "ניסוי NN - <שם>" עם המסמכים, ולידם requirements (החוברת מפורקת לשאלות ואיורים), simulations, images, datasheets ו־QA.md.

## צילומים – לפני המעבדה

הקובץ images/README.txt בכל ניסוי מפרט כל תמונה שצריך: שם הקובץ המדויק, ובאיזה איור ובאיזה מסמך היא תופיע. לפני המעבדה אלה צילומי מסך מ־Multisim, לפי simulations/multisim_build.md. שומרים כל תמונה בשם שברשימה (PNG או JPG) ואומרים ל־Claude "תריץ מחדש".

## אחרי המעבדה

1. שומרים בתיקיית images של הניסוי את כל צילומי הסקופ, כל אחד יחד עם קובץ ה־txt שהסקופ שומר לידו. אין צורך לשנות שמות.
2. כותבים ל־Claude למשל: "הכנסתי את צילומי הסקופ לניסוי 1, תכין את הדוח המסכם".
3. Claude מריץ קודם בדיקת קליטה. הוא יוצר טבלה (images/INVENTORY.md) של כל הצילומים לפי סדר הצילום, עם ההגדרות והמדידות של הסקופ. בטבלה מסומנים צילומים חשודים:
   - צילום שמתח המוצא בו לא מתאים לאף מתח הזנה;
   - מתנד שנעול על תדר המחולל (סימן לחיבור שגוי);
   - קבצים כפולים.
4. Claude שואל כמה שאלות קצרות:
   - איזה צילום שייך לאיזה סעיף (עם הצעה מוכנה);
   - ערכי הנגדים והקבלים שמדדת;
   - המספר הסידורי של הסקופ (מופיע בשורת הכותרת של כל צילום);
   - תאריך ההגשה;
   - האם משהו השתבש במעבדה.

   התשובות נשמרות בקובץ lab.json של הניסוי, ומשם הן נכנסות לעמוד השער.
5. ערכים שהסקופ לא מדד ישירות, כמו מתחי סף, Claude קורא מתוך העקום בצילום, ומציין בדוח איך נקראו.
6. הדוח נכתב לפי כמה כללים:
   - צילום אחד לכל שלב מדידה;
   - חישוב רק לפי הנוסחה שבחוברת;
   - ערכי רכיבים שנמדדו;
   - השוואות הוגנות;
   - הסבר לכל תוצאה חריגה;
   - מגבלת העמודים.

## אחרי שערכת דוח ב־Word

ברגע שפתחת דוח ב־Word ושינית בו משהו, Claude לא בונה אותו מחדש, כדי לא למחוק את השינויים שלך. כל תיקון נוסף נעשה ישירות בתוך הקובץ שלך:
- לפני כל סבב נשמר גיבוי בתיקיית _archive.
- הערות שהשארת ב־Word נקראות ומטופלות אחת אחת.
- אם המסמך פתוח ב־Word, התוצאה נשמרת בשם "… - מעודכן.docx", ו־Claude אומר לך איזה קובץ הוא העדכני.

## איך מוודאים שהכול נכון

- בדיקה אוטומטית של כל מסמך: מספור רציף, הפניה לכל איור וטבלה, מבנה שאלות זהה לחוברת, נוסחאות תקינות, עברית שאינה מתהפכת (כולל מספרים עם יחידות), וגוף שלישי בדוח המסכם.
- סקירה ויזואלית של כל עמוד אחרי המרה ל־PDF.
- כל מספר בדוחות נלקח ישירות מתוצאות הסימולציה, בלי הקלדה ידנית, ונבדק מול החישוב התאורטי.
- שלושה סוקרים בלתי תלויים (חישובים ופיזיקה, סימולציות, עריכה), כשהחוברת היא מקור האמת.
- כל הנחה או ערך שדורשים אימות שלך מודגשים בצהוב.

## חשוב לדעת

- הסקיל הוא כלי עזר ללמידה ולהכנה. ההבנה, הבדיקה והמסקנות שלך. בדוח המסכם יש הצהרה שהעבודה היא שלך, ולכן חשוב לעבור על כל מסמך ולוודא שאתה מבין ומסכים עם כל מה שכתוב בו.
- כדאי לבדוק מה מותר בקורס שלך לגבי שימוש בכלי בינה מלאכותית.
- החוברת היא מקור האמת. אם משהו בדוח סותר את החוברת – החוברת צודקת, ויש להגיד ל־Claude.
- פרטים אישיים (שם, ת.ז., טלפון) נשמרים רק בקובץ course.json שבתיקיית הקורס שלך.

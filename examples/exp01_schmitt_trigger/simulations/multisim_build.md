## הרכיב ב‑Multisim (משותף לכל המעגלים)

`Place ▸ Component` → Database: **Master** → Group: **CMOS** → Family: **CMOS_5V** (או **CMOS_10V**
למעגלים ב‑10V) → רכיב **4093BD_5V** / **4093BD_10V**. ברכיבי CMOS ההדקים VDD/VSS מוסתרים
ומחוברים לרשתות גלובליות: הצב מקור **VDD** (`Place ▸ Sources ▸ POWER_SOURCES ▸ VDD`) וקבע לו את
מתח ההזנה, ו‑**VSS/GND**. אם הרכיב "לא עושה כלום" — כמעט תמיד חסר מקור VDD.

> הערה: שמות המשפחה/הרכיב יכולים להשתנות מעט בין גרסאות Multisim; חפש "4093" בשדה החיפוש.

> **חשוב לפני שמשווים מספרים:** למודל 4093 בספריית Multisim יש ספים משלו, שאינם בהכרח ערכי
> ה־typ של דף הנתונים (2.9/1.9 V ב־5V). לכן קרא את $V_p$ ו־$V_n$ **מתוך הגרף של Multisim**
> (רמות הקבל העליונה והתחתונה, או נקודות המעבר בלולאה), והשווה את התדר לנוסחה המלאה עם הספים
> האלה. סטייה מ־1231 Hz שנובעת מספים אחרים במודל אינה שגיאה. ה־netlist‑ים משתמשים בספי ה־typ
> בדיוק.

## מעגל 1.1 — מתנד עם מחלק מתח (שאלה 9) → `q10_c11_multisim.png`

1. רכיב 4093BD (CMOS, תתאים ל‑6V — אם אין CMOS_6V השתמש ב‑CMOS_5V ומקור VDD = 6V, ובדוק שהספים
   יוצאים קרוב ל‑3V/2V; אחרת השתמש ב‑netlist `c11_astable_divider.cir` שהספים בו מדויקים).
2. חיבורים לפי תרשים 1.1: הדקים 1+2 (הכניסות) לצומת X · הדק 3 (מוצא) → **Rx = 60kΩ** → צומת X ·
   צומת X → **100kΩ** → GND · צומת X → **C = 10nF** → GND · VDD = 6V.
3. סקופ: ערוץ A על צומת X (הקבל), ערוץ B על המוצא. Timebase ≈ 200µs/div, Y/T.
4. הרץ (F5), עצור, וצלם שני מחזורים.
5. **צפוי:** הקבל עולה מ‑0 עד 3V תוך ≈0.60ms, ואז מתנדנד בין 2V ל‑3V; המוצא ריבועי 0/6V;
   T ≈ 0.47ms (f ≈ 2.13kHz); הקבל לעולם לא מגיע מעל 3.75V (מתח תבנין).

## מעגל 1.2 — עקומת חשל → `5.1.2_sim_5V.png`, `5.1.2_sim_10V.png`, `5.1.7_sim.png`

1. רכיב 4093BD, הדקים 1+2 מחוברים יחד = Vin, הדק 3 = Vout. VDD = 5V (ואחר כך 10V עם CMOS_10V).
2. מחולל אותות XFG1: **Sine**, תדר **5kHz**, Amplitude **2.5Vp** (ב‑10V: 5Vp), Offset **2.5V**
   (ב‑10V: 5V) — כך האות נע בין 0 ל‑VDD ולא חורג מהאספקה.
3. סקופ XSC1: ערוץ A = Vin, ערוץ B = Vout. בחלק Timebase לחץ **B/A** (מצב XY: B אנכי מול A אופקי).
   Channel A/B: 1V/div (ב‑10V: 2V/div).
4. הרץ וצלם את הלולאה. **צפוי:** לולאה מלבנית — המוצא יורד מ‑VDD ל‑0 ב‑Vin ≈ Vp (2.9V / 5.9V)
   ועולה חזרה ב‑Vin ≈ Vn (1.9V / 3.9V).
5. כניסה ריבועית (סעיף ז, 5V): ב‑XFG1 בחר **Square**, אותה תדירות/אמפליטודה/היסט. צלם XY.
   **צפוי:** במקום לולאה רואים בעיקר שתי נקודות בפינות (0,5V) ו‑(5V,0) — האות קופץ בין 0 ל‑5V
   ולכן אינו "שוהה" בתחום החשל.

## מעגל 1.3 — מתנד עם בקרת הפעלה → `5.2.2_sim_5V.png`, `5.2.4_sim_10V.png`

1. שער A של 4093BD: הדק 1 = Vcontrol, הדק 2 = צומת הקבל, הדק 3 = Vout.
2. **R1 = 10kΩ** בין הדק 3 להדק 2 · **C1 = 0.1µF** מהדק 2 ל‑GND · Vcontrol = VCC (מקור DC של 5V,
   ואחר כך 10V) · VDD = 5V (10V).
3. סקופ: ערוץ A = הקבל (הדק 2), ערוץ B = המוצא (הדק 3), Y/T, Timebase ≈ 500µs/div.
4. הרץ וצלם. **צפוי:** הקבל מתנדנד בין Vn ל‑Vp; f ≈ 1231Hz ב‑5V ו‑≈1233Hz ב‑10V לפי הנוסחה המלאה
   (נוסחת החוברת נותנת 1182 / 1208 Hz — ראה דוח מכין שאלה 8).
5. נסה גם Vcontrol = 0V: המוצא נשאר '1' קבוע והקבל נטען ל‑VCC — זו טבלת האמת של שאלה 7ב.

## חלופה: ייבוא netlist (ללא רכיב 4093)

`File ▸ Open` → סוג קובץ **SPICE netlist (*.cir)** → בחר קובץ מהתיקייה. השער ממודל במתג עם
היסטרזיס (ובמעגל 1.3 שני מתגים בטור = NAND), כך שהספים מדויקים בדיוק לערכי דף הנתונים.
דרגת המוצא היא נגד משיכה של 1 Ω ומתג עם Ron = 1 mΩ, כך שהמודל משנה את התזמון בפחות מ־0.1%
(התוצאות אמורות לצאת כמו ב־MATLAB: T = 0.470 ms, f ≈ 1231 / 1233 Hz).
`Simulate ▸ Analyses ▸ Transient` (זמנים לפי שורת `.tran` בקובץ), בחר את `V(cap)`/`V(out)`
(במעגל 1.2: `V(in)`/`V(out)`), והרץ. ל‑XY ב‑Grapher: הצג את `V(out)` כפונקציה של `V(in)`.
מגבלה: ייבוא מודל המתג (`.model … SW`) לא תמיד נתמך בכל גרסה — אם נכשל, השתמש בבנייה הידנית.
